02 INSIDE THE PIPELINE

From generated rows
to a service window.

The demo uses the trained model artifact itself, converted into a compact browser-readable format. No server receives or predicts from your inputs.

01 / DATA

Generate

8,000 seeded synthetic vehicle-service examples.

02 / PREP

Prepare

Impute, encode categories, and derive service progress.

03 / MODEL

Estimate

Average the leaf predictions from 120 decision trees.

04 / GUARDRAIL

Bound

Cap the model by the user's manual distance and time limits.

⟶ The time limit is converted to an estimated distance using the daily driving value entered above.

04 CLEAR LIMITS

A useful demo
knows what it isn't.

This is a classroom prototype that makes the machine-learning process visible. It is not a maintenance product.

01
Synthetic data only

Generated examples make the workflow reproducible, but do not represent real service records.

02
Not a diagnosis

The estimate cannot identify faults, inspect vehicle condition, or recommend repairs.

03
Manual first

Use the schedule in the owner's manual; the demo's output cannot delay the entered limits.

04
No data is uploaded

Browser inputs remain on this device. There is no account, API, or server-side prediction.
